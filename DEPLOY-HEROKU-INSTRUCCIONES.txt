OPCIÓN 1: EJECUTAR SCRIPT BATCH (MÁS FÁCIL)
================================================================================

1. Abre el Explorador de Archivos
2. Ve a: C:\Users\Marcelo\Proyecto\Agentes\whatsapp-agent
3. Busca el archivo: deploy-heroku-final.bat
4. Click derecho → "Ejecutar como administrador"
5. Sigue las instrucciones en la ventana que se abre
6. El script hará todo automáticamente:
   - Verificará la autenticación en Heroku (puede pedir login)
   - Inicializará Git si es necesario
   - Creará la app en Heroku
   - Configurará todas las variables de entorno
   - Hará el push del código
   - Verificará que la app esté corriendo

OPCIÓN 2: EJECUTAR SCRIPT POWERSHELL DIRECTAMENTE
================================================================================

1. Abre PowerShell
2. Click derecho → "Ejecutar como administrador"
3. Ejecuta este comando:

   Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser
   & "C:\Users\Marcelo\Proyecto\Agentes\whatsapp-agent\deploy-heroku-final.ps1"

QUÉ SUCEDE SI HAY ERRORES
================================================================================

Si la app no inicia:
1. Ve los logs: heroku logs --tail -a whatsapp-agent-marcelo
2. Verifica las variables de entorno: heroku config -a whatsapp-agent-marcelo
3. Intenta reiniciar: heroku restart -a whatsapp-agent-marcelo

Si Git está bloqueado:
1. Asegúrate de estar en PowerShell como administrador
2. Intenta ejecutar el script batch en su lugar

Si Heroku no está disponible en PATH:
- El script usa la ruta completa: C:\Program Files\Heroku\bin\heroku.cmd
