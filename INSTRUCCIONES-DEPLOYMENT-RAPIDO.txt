OPCIÓN A: HEROKU (Lo que está listo ahora)
═════════════════════════════════════════════════════════════════════════

El script hace:
  ✓ Inicializa Git
  ✓ Crea la app en Heroku (whatsapp-agent-marcelo)
  ✓ Configura todas las variables de entorno
  ✓ Hace push del código
  ✓ Verifica que funcione
  ✓ Te muestra la URL

PASOS PARA EJECUTAR:

1. Abre PowerShell como ADMINISTRADOR

   Formas de hacerlo:
   a) Presiona: Ctrl+Shift+Esc
   b) Escribe: PowerShell
   c) Click derecho → "Ejecutar como administrador"

2. Autentica con Heroku:

   heroku login

   Presiona Enter y completa el login en el navegador que se abre

3. Ejecuta el script de deployment:

   powershell -ExecutionPolicy Bypass -File "C:\Users\Marcelo\Proyecto\Agentes\whatsapp-agent\DEPLOYMENT-COMPLETE.ps1"

4. Espera a que termine (5-10 minutos)

   El script te mostrará:
   ✓ Estado en cada paso
   ✓ URL de tu app
   ✓ Comandos útiles

5. Tu app estará en vivo en:

   https://whatsapp-agent-marcelo.herokuapp.com

OPCIÓN C: RENDER.COM (RECOMENDADO - SIN AUTENTICACIÓN LOCAL)
═════════════════════════════════════════════════════════════════════════

Render es más automatizable y totalmente gratis:

PASOS:

1. Sube a GitHub:

   git init
   git remote add origin https://github.com/tuusuario/whatsapp-agent.git
   git add .
   git commit -m "WhatsApp Agent"
   git push -u origin main

2. Ve a: https://render.com

3. Click "New +" → "Web Service"

4. Conecta tu repositorio de GitHub

5. Render automáticamente:
   ✓ Detecta render.yaml
   ✓ Configura variables
   ✓ Deploya

6. Tu app en: https://whatsapp-agent-backend.onrender.com
