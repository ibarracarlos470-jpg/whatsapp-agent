RECOMENDACIÓN: USA RENDER (PASO A PASO)
═════════════════════════════════════════════════════════════════════════

PASO 1: Crear repositorio en GitHub
──────────────────────────────────────

Si no tienes GitHub:
  1. Ve a: https://github.com/signup
  2. Crea una cuenta
  3. Crea un repositorio nuevo "whatsapp-agent"

Si ya tienes GitHub:
  1. Ve a: https://github.com/new
  2. Nombre: whatsapp-agent
  3. Descripción: WhatsApp Customer Support Agent
  4. Click "Create repository"

NOTA: Copia la URL de tu repositorio (ej: https://github.com/tuusuario/whatsapp-agent.git)


PASO 2: Sube tu código a GitHub
─────────────────────────────────

Abre PowerShell en la carpeta del proyecto:
  cd C:\Users\Marcelo\Proyecto\Agentes\whatsapp-agent

Configura Git:
  git config user.name "Tu Nombre"
  git config user.email "tu@email.com"

Agregar GitHub como remoto:
  git remote add origin https://github.com/tuusuario/whatsapp-agent.git

Agregar y hacer push:
  git add .
  git commit -m "Initial commit - WhatsApp Agent"
  git push -u origin main

Si te pide autenticación:
  - En GitHub: Settings → Developer settings → Personal access tokens
  - Genera un token
  - Usa el token como contraseña


PASO 3: Conectar Render a GitHub
──────────────────────────────────

1. Ve a: https://render.com

2. Click en "New +" en la esquina superior derecha

3. Selecciona "Web Service"

4. Click en "Connect GitHub account"
   ► Autoriza a Render acceder a tu GitHub
   ► Selecciona tu repositorio "whatsapp-agent"

5. En la siguiente pantalla:

   Name:              whatsapp-agent-backend
   Runtime:           Node
   Build Command:     npm install
   Start Command:     npm start

6. Render automáticamente:
   ✓ Ve el render.yaml
   ✓ Configura todas las variables de entorno
   ✓ Inicia el build
   ✓ Despliega tu app

7. En 2-3 minutos tu app estará en vivo:
   https://whatsapp-agent-backend.onrender.com


PASO 4: Verificar que funcione
───────────────────────────────

Abre en el navegador:
  https://whatsapp-agent-backend.onrender.com/health

Deberías ver JSON con el estado de la app.


PASO 5: Configurar webhook en Meta (WhatsApp)
───────────────────────────────────────────────

1. Ve a: https://developers.facebook.com/

2. Selecciona tu app

3. Ve a: WhatsApp → Configuración → Webhooks

4. Callback URL:
   https://whatsapp-agent-backend.onrender.com/api/webhook

5. Verify Token:
   e24e347dcb0a98b4e98a95a467718248

6. Click "Verify and Save"
