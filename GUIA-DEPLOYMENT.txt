═════════════════════════════════════════════════════════════════════════
PASO 1: AUTENTICARSE CON HEROKU
═════════════════════════════════════════════════════════════════════════

OPCIÓN A: Login interactivo (recomendado)
─────────────────────────────────────────

1. Abre PowerShell como ADMINISTRADOR
   ► Presiona: Ctrl + Shift + Esc
   ► Abre PowerShell
   ► O busca "PowerShell" → Click derecho → "Ejecutar como administrador"

2. Ejecuta en PowerShell:
   heroku login

3. Presiona Enter
   ► Se abrirá un navegador automáticamente
   ► Completa el login con tus credenciales de Heroku

4. Vuelve a PowerShell
   ► Verifica el login con: heroku auth:whoami
   ► Deberías ver tu usuario


OPCIÓN B: Usar API Key directamente
────────────────────────────────────

1. Ve a: https://dashboard.heroku.com/account/applications/authorizations

2. Click en "Authorize new app"
   O si ya tienes una autorización:
   - Ve a "Personal API Keys" (en Settings → Account)

3. Click en "Generate API Key"

4. Copia la key (icon de copiar)

5. En PowerShell como ADMINISTRADOR, ejecuta:
   $env:HEROKU_API_KEY = 'pega_tu_api_key_aqui'

   Ejemplo:
   $env:HEROKU_API_KEY = 'c123d456e789f000'

PROBLEMAS COMUNES Y SOLUCIONES
═════════════════════════════════════════════════════════════════════════

PROBLEMA: "Heroku CLI no encontrado"
SOLUCIÓN:
  1. Descarga Heroku CLI desde: https://devcenter.heroku.com/articles/heroku-cli
  2. Instala en la ruta por defecto
  3. Reinicia PowerShell
  4. Intenta de nuevo

PROBLEMA: "No autenticado con Heroku"
SOLUCIÓN:
  1. Abre PowerShell como ADMINISTRADOR
  2. Ejecuta: heroku login
  3. Completa el login en el navegador
  4. Intenta el deployment de nuevo

PROBLEMA: "Error configurando variables"
SOLUCIÓN:
  1. Verifica que tienes acceso a la app:
     heroku apps:info -a whatsapp-agent-marcelo
  2. Si la app no existe, configura manualmente:
     heroku create whatsapp-agent-marcelo

PROBLEMA: "Git no está inicializado"
SOLUCIÓN:
  El script lo hace automáticamente. Si hay error:
  1. cd C:\Users\Marcelo\Proyecto\Agentes\whatsapp-agent
  2. git init
  3. Intenta el deployment de nuevo

PROBLEMA: "App no responde después del deployment"
SOLUCIÓN:
  1. Espera 5-10 minutos (Heroku puede tardar)
  2. Ver logs:
     heroku logs -a whatsapp-agent-marcelo --tail
  3. Ver si la app está corriendo:
     heroku ps -a whatsapp-agent-marcelo
